Generation 0

2,000 random formula trees

Each candidate randomly combines your 7 variables with +, −, ×, ÷. Almost all of them are nonsense — this is the unguided starting population before any selection happens.

Score every candidate

Evaluate against all 50 rows

Each formula predicts an r for every row; gplearn compares that to the real r and computes mean squared error. Lower error = fitter formula.

MSE = average( (formula(x,y,z,a,b,c,d) − r)2 ) across all 50 rows
Select → breed → mutate

The evolutionary loop

The lowest-error formulas survive. Pairs of survivors swap sub-trees (crossover); some offspring get a random tweak (mutation). This repeats for 25 generations.
